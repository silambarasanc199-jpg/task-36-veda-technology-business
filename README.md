# Veda Technology — Business & Services Website

A professional responsive business website developed as part of Veda Technology Web Development Internship — Task 36.

## 📌 Project Overview

This project presents Veda Technology as a technology and digital-services organization through a clean, responsive and professional web interface.

The website includes information about technology programs, IT and digital services, internship and training opportunities, FAQs and contact details.

## 🎯 Objective

- Build a professional multi-section business website
- Implement responsive web design
- Create reusable UI sections and cards
- Add JavaScript-based interactions
- Implement FAQ accordion functionality
- Apply basic SEO practices
- Create a mobile-friendly user experience

## ✨ Features

- Responsive navigation
- Professional business homepage
- About section
- Technology programs section
- IT & digital services section
- Internship and training section
- FAQ accordion
- Contact information
- Contact form validation
- Responsive desktop, tablet and mobile layout
- SEO-friendly page structure
- Back-to-top functionality
- Accessible and clean UI

## 🛠️ Technologies Used

- Responsive Web Design
